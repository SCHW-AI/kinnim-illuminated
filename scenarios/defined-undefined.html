Scenario 2: Defined with Undefined

קן סתומה + One חטאת

קן סתומה
(One חטאת, One עולה - not designated)
חטאת/עולה
חטאת/עולה
חטאת
1 חטאת can be brought, 2 birds must die

Why 1 חטאת can be brought:

No matter which bird we select as a חטאת, it is valid:

  • If we pick the defined חטאת → it's a valid חטאת
  • If we pick either undefined bird → bringing it as a חטאת defines it as such

Why we cannot bring a second חטאת:

If the first bird was undefined bird A (now defined as חטאת), then undefined bird B is now an עולה. Bringing it as a חטאת would mean bringing an עולה as a חטאת - invalid.

Why we cannot bring any עולה:

The bird we select might be the defined חטאת, so we would be bringing a חטאת as an עולה - invalid.
